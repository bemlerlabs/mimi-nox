# Golden Example

User asks for an investor pitchdeck.

Expected behavior:
- Create a complete storyline with cover, problem, solution, product, proof, market, roadmap, risk, ask, and appendix.
- Call `create_pitch_deck` with a safe descriptive filename.
- Mention the real deck path and preview path only after tool output exists.
- State assumptions clearly if the user did not provide business metrics or source material.
